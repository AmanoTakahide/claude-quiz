# Claude Associate 練習問題（公開用）

GitHub Pages で公開するためのフォルダです。画面は `index.html`、問題データは `data/questions.bundle.js` です。

- 元のフォルダ: `03_コード/Claude_Associate練習問題/`（問題の編集は、そちらで行う）
- 自作の練習問題です。公式の試験問題ではありません。
- 記録（履歴・成績）は、ブラウザの中に保存されます。端末ごとに別です。

## 更新の手順
1. 元のフォルダで問題を直し、`build_data.bat` を実行する。
2. `index.html`、`config.json`、`data/questions.bundle.js` を、このフォルダにコピーする。
3. `git add -A` → `git commit` → `git push`。数分で公開URLに反映される。
